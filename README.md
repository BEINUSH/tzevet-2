# מי זה? 🎯

משחק מולטיפלייר מקומי (LAN) לערב גיבוש - עד 16 שחקנים מצביעים מהטלפון על שאלות "מי הכי סביר ש...".

## איך זה עובד

1. המנחה פותח חדר מהמחשב/טלפון/טלוויזיה - מקבל **קוד בן 4 תווים** וקוד QR.
2. כל שאר המשתתפים נכנסים מהדפדפן בטלפון (בלי התקנה), מזינים את הקוד ואת השם שלהם.
3. המנחה לוחץ "התחל משחק" (מינימום 3 שחקנים, מקסימום 16).
4. בכל סיבוב עולה שאלה, וכל שחקן מצביע **אנונימית** על אחד השמות מהרשימה.
5. ברגע שכולם הצביעו (או שהמנחה לוחץ "גלו תוצאות עכשיו") - מוצגות התוצאות עם מי קיבל הכי הרבה קולות 👑.
6. בסוף כל השאלות מוצג סיכום ערב עם "מלך/ת הכתרים" - מי נבחר הכי הרבה פעמים.

הכל רץ **מקומית**, בלי מסד נתונים, בלי אינטרנט - רק רשת Wi-Fi משותפת.

## הרצה

דרוש [Node.js](https://nodejs.org/) גרסה 18 ומעלה.

```bash
# 1. התקנת תלויות (פעם אחת)
cd client && npm install && npm run build
cd ../server && npm install

# 2. הרצת השרת
npm start
```

השרת יעלה בכתובת `http://localhost:3000` ומגיש גם את הקליינט וגם את ה-Socket.io.

## חיבור מהטלפונים (חשוב!)

כדי שכולם יוכלו להתחבר מהטלפון, המנחה חייב לפתוח את המשחק דרך **כתובת ה-IP המקומית** של המחשב (לא `localhost`), כי localhost נגיש רק מהמכשיר עצמו.

1. ודאו שכל המכשירים (המחשב/מחשב המנחה והטלפונים) מחוברים לאותה רשת Wi-Fi.
2. מצאו את כתובת ה-IP המקומית של המחשב שמריץ את השרת:
   - macOS: `ipconfig getifaddr en0`
   - Linux: `hostname -I`
   - Windows: `ipconfig` (שורת "IPv4 Address")
3. פתחו בדפדפן המנחה: `http://<IP-של-המחשב>:3000` (למשל `http://192.168.1.20:3000`)
4. לחצו "פתיחת חדר (מנחה)" - יופיע קוד + QR. שאר המשתתפים סורקים את ה-QR או נכנסים לאותה כתובת ולוחצים "הצטרפות למשחק".

> טיפ: אם מציגים את מסך המנחה על טלוויזיה/מקרן, כל השחקנים רואים את השאלה והתוצאות יחד עם ההצבעה מהטלפון האישי.

## מבנה הפרויקט

```
server/   Node.js + Express + Socket.io - כל הלוגיקה של החדרים, ההצבעות והשאלות (בזיכרון, ללא DB)
client/   React (Vite) - מסך מנחה, מסך הצטרפות ומסך שחקן, מותאם למובייל ו-RTL
```

### טכני

- **Backend**: Express משרת את קבצי ה-build הסטטיים של React, ו-Socket.io מנהל את כל הריל-טיים (הצטרפות, הצבעות, מעבר שאלות).
- **State** מוחזק לגמרי בזיכרון של השרת (Map של חדרים) - אין מסד נתונים, נעלם כשהשרת נסגר.
- **שחזור חיבור**: אם טלפון ננעל/התנתק לרגע, הוא מתחבר מחדש אוטומטית לאותו מקום במשחק (טוקן שנשמר ב-`sessionStorage`).
- **אנונימיות**: השרת חושף רק את ספירת הקולות המצטברת בתום כל סיבוב, לא מי הצביע למי.

### פיתוח (dev mode)

להרצה עם hot-reload בזמן פיתוח:

```bash
# טרמינל 1
cd server && npm start

# טרמינל 2
cd client && npm run dev -- --host
```

ה-dev server של Vite (ברירת מחדל פורט 5173) מפנה בקשות `/socket.io` לשרת ב-3000 (מוגדר ב-`client/vite.config.js`).
